入库限制

原型边界

  • 当前检索索引仍保存在 API 进程内存，API 重启后需要重新加载索引。
  • 检索使用配置的 embedding 模型进行向量召回，并与 BM25 组合；Model Service 仍为 stub。
  • 文档术语库支持入库检测与空闲时人工触发的 AI 抽取，用于缩写展开召回。
  • grounded 模式调用配置的主 AI 引擎，答案仍经过服务端证据 ID 校验。
  • 当前 CORS 允许跨域，尚未接入鉴权和 TLS，不建议直接暴露公网。

危险操作

清空文档、版本、Para-ID 切片和待处理文件。答案快照与人工反馈评测记录会保留。
